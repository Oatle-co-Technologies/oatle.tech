# Fixed rand invoice discounts

The new-invoice form offers Percentage (%) or Fixed amount (R). A fixed R50 discount on the R350 animated invitation creates an exact R300 invoice. A fixed discount is stored in nullable `invoices.discount_fixed` (numeric, two decimals); NULL preserves the existing percentage semantics, including historical invoices. The API rejects negative, non-finite, fractional-cent and above-subtotal discounts, and simultaneous fixed and nonzero percentage discounts. Percentage calculations now also round currency consistently to cents using Decimal/ROUND_HALF_UP.

Payment/status updates preserve the saved discount and total together, including older callers that omit the new field. Existing saved invoices retain their locked pricing controls. Fixed discounts appear as rand amounts in the invoice list and breakdown. Neither the migration nor verification creates a production test invoice or sends email.

Apply `sql/005_fixed_invoice_discounts.sql` before code release. `scripts/migrate_fixed_discounts.py` uses the existing production DATABASE_URL inside Vercel, without exporting the sensitive connection. The runner locks the financial tables briefly, fingerprints all historical invoice/payment fields, applies the additive column in one transaction, and rolls back on any mismatch. Use a one-off deployment build command to run it before Next.js; retain normal project build settings.

EmailJS receives the exact rand discount in `discount_amount` and the saved remaining balance in `amount`/`amount_due`. It also receives `discount_label`, e.g. `Discount (fixed amount)` or `Discount (10.00%)`. In the EmailJS template replace `Discount ({{discount_percent}}%)` with `{{discount_label}}` to display the chosen discount type. The old template remains compatible: its percentage is the rounded percentage equivalent for presentation only, and is never used to calculate a fixed discount or invoice total. Automatic approval review blocked separate EmailJS dashboard access; the template was not edited by this change.
